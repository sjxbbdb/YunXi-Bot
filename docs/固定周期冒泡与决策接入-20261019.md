# 固定周期冒泡与决策接入

用户要求固定十至十五分钟检查一次，并明确分工：Laya只根据近期情况判断是否适合打扰；人格、画像和记忆只交给DeepSeek决定表达。DeepSeek近期聊天优先，没有近期聊天可以从已确认画像和记忆取材。这一授权取代 D158 的60–120分钟随机生成尝试和不经Laya的路径。

## 本轮实现

- 固定15分钟检查，后台首次可用时可检查一次；后台忙于已确认跟进或记忆整理时顺延，不补发积压轮次。夜间23–08静默。
- 每次检查先持久记录，Laya选择speak/hold/quiet；只有speak且策略允许才调用DeepSeek。未知、错误、不确定一律不生成并留痕。Laya的安静/暂缓不消耗DeepSeek生成预算。
- Laya只接收当前本地时间、最近通知距今时间及一小时内次数、通知间隔是否允许、限长近期用户原话；不接收人格、画像、常驻记忆或旧通知正文，不负责选话题。现状是已有观察，不将没有记录推断为空闲，也不读取屏幕或假定日历状态。决策情境限定700 UTF-8字节，为本地模型问题头预留空间；不会修改资料原文。
- Laya允许后，DeepSeek完整加载人格、画像及有效常驻记忆，优先延续48小时内真实聊天。没有聊天可用已确认兴趣，不凭空编造最近经历。没有任何材料保持安静；画像有兴趣不直接让Laya放行。
- DeepSeek可再次选择安静；生成后重验用户输入、记忆撤回、人格/画像变更、时间和通知间隔。只发Mac陪伴通知，不获工具执行或资料写入权限。
- 沿用既有审计事件，不增加依赖或台账版本。调用预算与邮件独立。
