# UI 设计 Skill 安装与使用（2026-10-23）

为把云熙窗口做成真正的 macOS 应用，安装了两个用户级 skill 到 DSH 的目录 `~/.agents/skills/`。

## 已安装

| Skill | 来源 | 内容 |
|---|---|---|
| `apple-design` | <https://github.com/dickwu/apple-design-skill> | Apple HIG 评审器：123 页 HIG 参考（含 macOS 窗口/工具栏/侧栏/材质/色彩/字体/无障碍），设计审查流程与 craft lens |
| `macos-design-guidelines` | <https://github.com/ehmo/platform-design-skills>（`skills/macos`） | macOS HIG 的可执行规则：菜单栏、窗口、unified toolbar、源列表侧栏、键盘、指针、系统材质、语义色、无障碍 |

安装命令（可复现）：

```bash
mkdir -p ~/.agents/skills
git clone --depth 1 https://github.com/dickwu/apple-design-skill ~/.agents/skills/apple-design
git clone --depth 1 https://github.com/ehmo/platform-design-skills /tmp/pds
cp -R /tmp/pds/skills/macos ~/.agents/skills/macos-design-guidelines
```

安装后 DSH 在下一轮自动把它们加入 skill 目录，用 `skill` 工具加载。

## 用在云熙上的规则

- 标准窗口与 traffic lights；可缩放、全屏、记忆窗口尺寸。
- unified title bar + toolbar；工具栏命令同时存在于菜单栏。
- 侧栏用源列表样式、`.sidebar` vibrancy、系统选中色、可折叠。
- 只使用语义色（label/secondary/separator/controlBackground/controlAccent），不做应用内深色开关。
- SF 字体，13pt 正文、11pt 辅助；最小控件 28×28。
- 输入框、搜索框、下拉、按钮使用 AppKit 标准控件。
- 完整菜单栏：App/File/Edit/View/Window/Help，标准快捷键。
- hover、右键、键盘导航、Reduce Motion/Reduce Transparency 兼容。
