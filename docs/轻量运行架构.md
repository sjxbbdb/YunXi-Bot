# DeepSeek 生成与本地辅助模型

2026-10-15，按用户“闲聊和任务都走 DeepSeek，本地只放辅助模型”的选择实施。2026-10-16按用户批准补齐连续对话工具供给，架构依据为 ADR D142、D143。

## 当前分工

| 能力 | 模型与位置 | 入口 |
|---|---|---|
| 闲聊、任务规划与执行 | DeepSeek `deepseek-flash`，远端 | `chat`、`do`、`resume`、daemon 目标任务 |
| 摘要、画像候选、主动陪伴表达 | 同一 DeepSeek 端点 | 会话压缩、`profile --learn`、`agent`、daemon 陪伴 |
| 输入分类、记忆需求、方案选择与介入建议 | Laya multilingual，本机 MPS | 回环端口 17870 |
| 语义向量记忆与知识检索 | EmbeddingGemma 2 文本编码器，本机 CPU | 回环端口 17873，按需启动 |

聊天输入仍先判断意图，Laya结果用于回复模式建议；DeepSeek始终可按连续对话提出工具调用，执行仍经过原有约束与审批。chat使用非阻塞ask_user，问完即结束当前轮，下一条消息才是答案；同批其他动作等待回答。阻塞式ask_user保留给独立任务步骤。
同一会话可以在两种模式间切换并保留历史。分类弃权、未知结果、服务不可用或分类审计失败时停止本轮。
`do`、`resume` 与 daemon 的规划、执行、方案生成都使用 DeepSeek，包括短步骤与对话类型步骤。

自动思考按用途决定：闲聊默认关闭，规划和分析开启；显式 `--thinking on/off` 优先。
摘要、画像提炼与主动表达保留短输出用途的关闭思考设置。

人格、画像、记忆和资料仍在本地保存，相应上下文与工具结果会随生成请求发往 DeepSeek。
目标任务每阶段刷新人格、画像、常驻记忆、项目规则及检索上下文；聊天私人记忆仍使用既有召回方式，
新语义记忆主要用于目标任务。chat需要资料时可以调用 `knowledge_search`，不再因一句简短回答被判为闲聊而失去工具。

## 内存与启动

本机 Gemma 4 / Qwen3.5-9B 的生成服务已停止，17872 端口未监听，权重仍保留在磁盘。
2026-10-15 19:35 的进程 RSS 快照：Laya 约 1.00 GiB，EmbeddingGemma 2 约 1.81 GiB，合计 **2.805 GiB**。
这是两个辅助服务的 RSS 之和，不是整机内存、统一内存总分配或长期峰值；macOS 文件缓存也不包含在这个数字内。
原始快照：resources.json（本机私有报告：`data/benchmarks/input-routing/resources.json`，不随仓库发布）。

默认 Mac 安装器只准备辅助模型环境、Laya 与 Rust release；新机器的向量权重按 [macOS 开发指南](macOS开发.md) 准备。
主流程不会启动 MLX，也不会在远端错误时回落加载本地生成模型。实验入口 `think --provider local` 与手动启动脚本保留；
只有明确使用它们才会重新加载生成权重。`do/resume --provider local` 已拒绝。

```bash
./启动.command chat
./启动.command do "读取 README.md 并总结项目用途"
./启动.command resume <任务ID>
```

所有生成需要可用网络与 DeepSeek 凭证。凭证只从环境变量 `YUNXI_BOT_DEEPSEEK_KEY` 或数据目录的
`secrets/deepseek.key` 读取，不写入模型配置、台账或报告；本机凭证文件权限为 0600，已被 Git 忽略。

格式检查、debug/release 构建、Clippy `-D warnings` 通过。保留的本地实验协议另有 23 项 Python 测试通过。
辅助表达的介入选择使用固定替身以确保表达分支执行；其他专项使用真实 Laya 与向量服务。
测试脚本名称 `e2e_local_auxiliary.py`、`e2e_local_task.py` 为历史名称，当前内容已改为 DeepSeek 验收。

Laya 的意图分类另行计分：开发题 **26/28**，冻结后的验证题 **10/12**，合计 **36/40**。
开发题参与过判据调整，不能把合计当作独立测试集准确率；引用命令、混合意图仍会误判。
模型尚未后训练或概率校准，其选择不能代替动作授权。

没有进行 7×24 压力、长期休眠唤醒、真实私人资料准确率或全面提示注入测试。
远端不可用时生成会明确失败，不自动切换到大体积本地模型；联网依赖与 API 费用是当前方案的取舍。
