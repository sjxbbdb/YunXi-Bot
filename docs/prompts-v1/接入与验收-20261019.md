# 提示词接入与分步验收

2026-10-19。源码接入和本轮分步验收完成；常驻后台尚未切换。本记录不包含私人灵魂、画像或真实邮件。

后续已补充[多轮真实聊天与任务链路验收](多轮真实链路验收-20261019.md)，包含实际调用、首次失败、修复及复测；下文是接入阶段记录，不代替后续结果。

## 实现

- 生产正文集中在`crates/yunxi-bot-core/src/prompts/`，由编译期include_str加载；设计说明、参考文档和验收矩阵不发送给模型。不新增模板引擎或运行依赖。
- ToolRunner每轮请求带当前工具目录；目录不进入会话历史。Plan/Options仅接收实际能力参考，仍不执行工具。61项工具导航用目的/前置说明，参数继续来自schema，未知MCP按当前限定名和有界说明呈现。
- 主对话、步骤执行、CLI/core规划和选项接入共享职责。完整保留既有领域操作细则，移除与人格冲突的固定语气要求，协调旧Edge默认描述。
- 开机、冒泡和确认跟进共用表达约定，各有自己的职责和输出约束。冒泡目标80字符，原运行接收上限100保持；问候目标120字符，原硬上限160保持。人格/画像容量、原文和取材范围不变。
- 记忆提取、画像提议、摘要及邮件拟回复契约分离。收信审理和邮件写作继续复用已有完整正文；不将陪伴口吻带入收件人正文。
- 画像提取回查真实台账原话，排除工具、截图、检索上下文和助手文本；没有来源的旧会话不提取。摘要保留来源角色及调用关联，不复制仅供当前进程使用的私有观察。
- Laya时机及其他判断保留现有键、state范围、降级和策略消费方式。兼容路由、诊断入口与向量编码没有改成新后台服务。

## 已发现并修复的问题

首次真实冒泡6项中5项通过：只有工具请求时，模型仍解释自己不能查天气。第一次加强正文后8项中6项通过，历史任务仍可能被当作当前交流。

修复共用规则的作用域和冒泡输入包装：明确当前无新请求、historical_context只供取材；没有独立个人话题时必须静默，任务跟进由对应模块承担。加入邮件、日程任务变体，不用“天气”关键词做过滤。修复后第三、四次均8项全部通过；失败证据保留。

工具选择首次50/50通过，后续复测49/50：地点查询同时发起了重复的网页搜索。保留严格判定，补充通用顺序：专用工具覆盖事实时先读其结果，缺失、歧义或用户要求交叉核实时再补来源；不影响互不重复的查询并行。该用例连续3次通过，最终整组50/50通过。

邮件首次15项中14项通过，剩余输出为“暂无法确认参加”，被测试按“确认参加”子串误判为接受邀约。先用反例测试复现，再仅对两种承诺短语补上紧邻否定识别；肯定承诺、双重否定和隐私词检查仍拒绝，生产邮件提示词及解析器未为此放宽。复测14项通过、1项网络错误；只补跑网络失败项后通过，不能把这次结果写成单轮15/15。

## 最终结果

- `cargo fmt --all -- --check`、`cargo build`、`cargo clippy --all-targets`通过，无warning；`git diff --check`通过。
- `cargo test`：核心1267项、CLI128项、集成2项，共1397项通过。38项显式外部环境测试默认忽略，未计入通过数；本轮所选真实模型测试另列如下。
- DeepSeek工具选择：最终50/50，加载全部61项真实schema，只检验提议，不派发动作。
- DeepSeek冒泡：最终两轮分别8/8；覆盖近期阅读/烹饪话题、话题结束、空输入、三种历史工具任务和注入指令。自动检查只证明正文/静默、长度、无工具请求及敏感词提示通过，不等于全面的陪伴质量评估。
- Laya：两组近期上下文请求可正常处理并返回合法选项，包含长上下文。只证明协议和输入范围兼容，不证明判断准确率；没有向它传人格、画像或常驻记忆。
- DeepSeek开机：两种合成人格×早晚时段，4/4符合事实和输出约束。人工查看发现语气差异仍有限，不能据此声称人格风格已经充分体现。
- DeepSeek邮件：15个合成收发场景均取得通过结果，其中一项在网络失败后单独补跑；未调用原生接口、未发信或通知。
- 三份私人原文（灵魂、运行人格、运行画像）与接入前基线哈希一致。未将这些原文复制进提示词资产或验收文档。

实测生成模型回执为`deepseek-flash`。最终证据对应`tool-selection-r3.json`、`bubble-expression-r3/r4.json`、`laya-context.json`、`startup-style.json`、`mail-workflows-r2.json`及`mail-network-retry.json`；工程检查见`*-final.log`。前次失败记录保留，未覆盖或删除。

## 验收边界

工具选择测试只验证模型提出的首批名称及参数，不证明后续任意任务均能成功。人格对照使用合成设定；语气是否符合用户期待仍需实际聊天体验。确定性门禁、逐封发信审批、订单核验和支付交人均保留。
