# 向量模型实测（2026-10-15）

本轮先选型，再接入任务记忆和知识库。候选为 intfloat/multilingual-e5-small 与 Google EmbeddingGemma 2 文本版；现有 Gemma 4 生成模型与 Laya 决策模型不参与这次排名。

## 试题与判据（测试前确定）

题库：`models/eval/embedding-retrieval-v1.json`，全部为合成数据，无真实私人资料。
94 条资料、73 条查询；其中 12 条只用于有答案/无答案阈值校准，61 条用于正式评估（55 条有答案、6 条无答案）。
覆盖个人记忆、关系事件、生活常识、基础知识、文档规程、代码标识符、平台差异、中英跨语言、否定与边界、同义改写、工作区隔离，以及无答案查询。

- 用同一资料、问题、正确资料 ID 与作用域过滤规则；按问题相关性评分，不让生成模型充当裁判。
- 先比较各类 Top-1 召回率、整体 Top-3 与 MRR；再看无答案误接纳以及 CPU 查询延迟、索引速度和进程峰值内存。
- 均用 CPU、4 个 PyTorch 线程、float32 权重、8 条资料一批，查询逐条执行。先固定热身，再计时。
- 使用完整原生维度：E5 384 维，EmbeddingGemma 2 为 768 维。两者均平均池化并 L2 归一化。
- 输入前缀按各模型官方契约适配：E5 的 query/passage，与 Gemma 的 search result/document。正文完全相同；前缀不是额外信息。
- 两个候选下载与 SHA256 校验全部通过后才开始。每个候选用独立进程，退出释放后再加载下一个；不同时加载。
- 正式测试集不参与阈值选择；单一相似度阈值是否可靠也必须通过测试，不能把相似度当成正确概率。
- 取舍优先质量。若质量差异小于一个正式正例（1/55），再由延迟和内存决定；质量差异明显时保留效果更好的模型，报告资源代价。

工作区过滤由确定性代码完成，不能把跨项目隔离交给向量相似度。题库中的注入样例也只是资料，不能用来修改审批策略。

## 复跑

```bash
.venv/bin/python scripts/fetch_embedding_candidates.py
.venv/bin/python -m unittest scripts.test_benchmark_embeddings -v
.venv/bin/python scripts/benchmark_embeddings.py
```

报告写入 `data/benchmarks/embeddings/`，每份保存题库 SHA256、固定模型版本、逐题排名、校准阈值、时间和峰值 RSS。
下载器复用现有 aria2 断点续传与 SHA256 校验；镜像内容必须与官方固定版本哈希一致。
本轮不更新依赖、不启动未知远端代码；推理阶段设置 Hugging Face / Transformers 离线模式。

## 范围

这是本项目合成题集的检索比较，不等于公开榜单或真实用户分布下的准确率。
暂不评估图像/音频/视频嵌入、长文直接编码、向量索引百万级扩展或 24 小时常驻。

官方依据：[E5 模型卡](https://huggingface.co/intfloat/multilingual-e5-small)、[EmbeddingGemma 2 开发指南](https://developers.googleblog.com/embeddinggemma-2-the-developer-guide/)。

## 实测结果

Apple M2 Max，64 GB；CPU 4 线程、float32、单模型独立进程。

| 指标 | E5-small | EmbeddingGemma 2（文本） |
|---|---:|---:|
| 首位命中（55题） | 78.2% | 89.1% |
| 前三位命中（55题） | 92.7% | 98.2% |
| MRR | 0.8601 | 0.9376 |
| 无答案拒绝（6题） | 100.0% | 100.0% |
| 阈值后正例仍被接纳 | 60.0% | 94.5% |
| 查询中位延迟 | 7.61 ms | 49.86 ms |
| 查询P95 | 11.09 ms | 52.48 ms |
| 94条资料建索引用时 | 0.23 秒 | 1.52 秒 |
| 进程峰值内存 | 0.92 GiB | 2.15 GiB |

保留 **EmbeddingGemma 2 文本编码器**：首位多命中6题，前三位多命中3题；约50ms的CPU单查询延迟和2.15GiB进程峰值在本机可接受。E5权重从本次下载目录移除，固定版本清单和报告仍保留以便复现。

不能把阈值当安全保障：两者都把“删除导入副本”与“删除原始文件”的相关片段排错。Gemma 对原子替换的中英改写仍排到第15；向量检索必须结合原文证据和确定性策略。

Gemma 的校准阈值为 0.751885，E5 为 0.891965。该阈值只来自12道校准题；无答案评估只有6题，不能据此宣称开放世界拒答可靠。

原始结果：Gemma逐题报告（本机私有报告：`data/benchmarks/embeddings/embeddinggemma-2.json`，不随仓库发布）、E5逐题报告（本机私有报告：`data/benchmarks/embeddings/multilingual-e5-small.json`，不随仓库发布）。原始记录在本机忽略目录。

题库 SHA256：`533b330ef317e7e124d90065789d8e76618f14d7a028f91f5296e988304ce190`。
