# 开机关心与主动冒泡

按用户要求增加两条陪伴入口：每次系统开机后结合时间与当地天气问候；根据近期聊天不定时主动聊两句。沿用现有人格、画像、记忆、模型调用预算与 Mac 通知，不新增常驻模型或运行依赖，不改变台账版本。

## 每次系统开机

`daemon --startup-care` 显式启用。常驻随 macOS 用户登录启动，所以开机登录后可运行；同一台账按 macOS 实际开机批次最多一次。2026-10-19 经用户批准改用 `kern.bootsessionuuid`，不再以自然日或后台进程启动代替系统开机：**同一次开机内后台重启、重新部署、跨日和休眠唤醒均不额外触发；同一天真正重启电脑可以再次问候**。本批次首次启用时可以触发，不能据此声称用户刚刚开机。

- 2026-10-19 按用户要求改为模型表达：统一Identity完整读取人格和画像，依次调用 `now`、`mac_location`、`mac_weather`，把工具返回的本地时间及经过校验的天气事实交给DeepSeek，生成自然的一至三句关心。没有固定早安、午安或穿衣文案，不把原始人格内容写进公开测试或文档。
- 23:00–05:59 同样取时间、天气并调用模型，语气以轻柔关心为主；不声称知道开机原因、用户没睡或正在加班。这个用户明确要求的单次启动例外不放开普通夜间冒泡。
- 天气来自 Open-Meteo 预报，校验日期、时效、小时数组、单位、数值范围及与系统时区的一致性。提供当天剩余时段的最低/最高温、降雨概率和风速；只在同一天较晚时段有至少5℃下降证据时提供降温字段，没有昨日数据就不提供昨日比较。模型收到事实而非预写的建议句子。数据不足时显式提供天气不可用，要求如实说明、不编造衣着建议。
- `mac_location` 使用 macOS CoreLocation 单次请求，要求位置不超过 5 分钟、系统精度在 20 公里以内；原生边界内将经纬度取一位小数，约 10 公里网格，只有粗化后的位置发送给天气服务。没有持续追踪，不用 IP/VPN 地点替代，不将坐标、原始天气响应或带坐标的 URL 写入台账。macOS 自身定位服务的数据处理不属于 Bot 的本地台账。
- `mac authorize location` 请求系统授权；普通调用不自动弹权限框。初始化等待系统首次权限回调，避免新进程尚未初始化就误报未授权。定位和天气工具的对话持久记录均使用私有占位。
- 取材和无工具模型生成在独立线程；主循环负责状态提交和通知，开机生成期间暂缓其他陪伴模型工作，邮件巡检继续运行。原生工具仍有既有串行锁，定位最多18秒、天气请求最多18秒，模型请求超时45秒；首次查询可能短暂延后其他原生读取，不宣称零阻塞。
- 启动前先落开机批次去重及尝试标记，计入陪伴/记忆整理共用的滚动24小时48次预算；崩溃或通知不明时本次开机不自动重发，并记录降级。天气失败仍可由模型生成明确说明的关心；时间、人格读取或模型失败不使用固定话术替代、不通知。模型输出为空、截断、超长、含工具调用或凭证提示时拒绝投递，成功模型调用记录用量。取材超过5分钟或跨日丢弃。

- 开机批次读取或校验失败时显式记录降级，不退回日期去重。旧台账缺少批次标识的记录通过系统开机时间保守关联；本次开机以来已有尝试则不重复，之前开机的旧记录不占用本次机会。历史台账字节保持，既有事件数据附加批次字段，不新增事件类型或迁移版本。

## 近期话题冒泡

`daemon --agent` 每15分钟检查是否适合聊两句，优先使用近48小时、未撤回的真实用户聊天；没有近期聊天时可以使用已确认画像与常驻记忆中的兴趣。已确认的到期跟进和待整理记忆优先，忙时顺延。

- 最近 6 条用户原话（每条限长）、已确认的画像/常驻记忆和最近 4 条陪伴通知作为取材；不是从邮件或网页接收“用户授权”。撤回之前的聊天及通知不再用于此表达。
- 固定15分钟检查，首次可用可以检查一次；检查先落台账，重启、静默或失败不重复检查。Laya只判断此刻是否适合打扰，输入是本地时间、近期用户原话、最近通知时间/频率和间隔策略结果；人格、画像、常驻记忆及旧通知正文不进入Laya，只交给DeepSeek选话题、组织表达。只有speak且策略允许才调用DeepSeek；hold/quiet不生成，未知或失败明确降级。检查频率不等于通知频率，没有共用每日三次通知上限。
- 23:00–08:00静默，距离真实用户输入或最近已投递陪伴通知至少60分钟；仅冒泡自身无回应按2/4/8小时退避，开机问候不再累加次数。DeepSeek表达与记忆整理共用48次/24小时预算，Laya检查不占用该生成预算。没有聊天、画像或有效常驻记忆时保持安静，DeepSeek仍可返回 `-` 不通知。
- 表达不超过 100 字，提示模型避免重复、说教、要求回应、依赖暗示及敏感事项在锁屏上的复述。相同最近正文确定性去重；语义相近但措辞不同的重复仍需后续体验评估。
- 发送前再次检查最新用户输入、撤回状态、完整人格/画像/常驻记忆、间隔、静默和5分钟有效期；期间资料变化则弃用旧表达。不会据聊天片段自行写日历、发邮件或执行电脑动作，也不会把表达当成正式记忆。
- 内容记录在现有 `CompanionGenerated`，投递记录在 `NoticeSent`，标明 `kind=bubble`；开机记录标明 `kind=startup_care`。Mac 是当前出口，未来前端可复用内容及回执；本轮没有建立前端推送服务。
