# 本地陪伴 T3：本地记忆流水线

状态：2026-10-24，端到端通过。

## 目标

把陪伴记忆提炼从 DeepSeek 云端切到本地，并形成可验证的闭环：

```text
ConversationObserved
  ↓
Laya 门控（store / skip，带敏感信息硬拦截）
  ↓ store
本地 Gemma 抽取结构化候选（kind/text/quote/source_seq）
  ↓
自动确认（高置信门控通过）
  ↓
MemoryRecorded（本地台账）
  ↓
EmbeddingGemma 向量化（vectors/memory.json）
```

## 实现

- daemon 的陪伴 thinker 从 `DEEPSEEK_FLASH` 改为 `LOCAL_GEMMA`；记忆提炼与陪伴表达都走本机 17872。
- `CompanionWorker::with_decider` 接入 Laya；每条 `ConversationObserved` 先过门控。
- 门控不是纯 Laya：实测 Laya 对“想叫你姐姐 / 别叫宝宝 / 花生过敏”等样本会误判 skip，因此增加：
  - 确定性记忆线索（“以后/记住/我喜欢/别叫/过敏/我下/约定”等）；
  - 敏感信息硬拦截（密码、密钥、身份证、银行卡、验证码、token 等）；
  - 失败/非法选择默认 skip，失败原因写台账。
- Laya `store` 或记忆线索命中时，调用本地 Gemma `MEMORY_EXTRACT`；候选取自本轮原文 quote，最多 4 条。
- 门控通过后自动确认候选，写 `MemoryRecorded`；随后 `warm_memory_vectors` 用本地 EmbeddingGemma 重建 `vectors/memory.json`。
- 没有可用本地模型时只记录降级，不回落 DeepSeek。

## 验收

临时数据目录：`/tmp/yunxi-t3-home`，无 `secrets/deepseek.key`；本地 Gemma + Laya + EmbeddingGemma 均运行在回环端口。

输入：`我以后想叫你姐姐。`

结果：

```text
info_triaged   phase=gate_store, reason=laya_store
memory_proposed kind=preference, text=以后想叫你姐姐
memory_recorded id=candidate-1-0
vectors/memory.json 生成
```

daemon 输出：`[陪伴] 已自动写入 1 条记忆并完成本地向量化。`

同时验证：
- 敏感文本“我的密码是 abc123”被 `sensitive_secret` 拦截，不进入模型和记忆。
- Laya 不可用/非法选择时默认 skip（degraded 写台账），无云端回落。
- 单元测试：`t3_gate_tests` 3 项（store、skip/invalid、memory cue/secret）。

## 已知限制

- Laya 647M 对记忆语义判断弱，当前是“Laya + 线索兜底”的混合门控；后续可用更多样本校准，或让本地 Gemma 做第二意见，但不能悄悄绕过 Laya。
- daemon 需要本机模型正在运行；未运行时记忆流水线降级，T4 处理闲置调度/本地服务拉起。
- 自动确认只覆盖门控通过的本轮候选；没有置信度分数，后续可加人工复核队列。
- 向量化是重建式（`vectors/memory.json`），不是独立向量数据库；当前个人规模足够，超过上限再换 ANN。
