## 使用与停用

```bash
./启动.command mac status
./启动.command check --mail-source mac --dry-run
./启动.command autostart-status

# 当前使用的登录自启配置；以后重新安装可复用：
./启动.command install-autostart -- --mail-source mac --assistant-interval 60 --limit 100 --task-interval 0 --judge-every 0

# 停止后台服务，保留台账、邮箱和日程：
./启动.command uninstall-autostart
```

日志：`data/logs/daemon.stdout.log`、`daemon.stderr.log`。台账继续使用既有InfoFetched、InfoTriaged、DecisionAsked/Resolved与NoticeSent事件，未改格式。来源异常和失败投递保留原因，不能解释成“没有新邮件”。

## 尚未验证或仍有限制

没有进行长时间常驻、注销重登录、断网恢复及睡眠唤醒验收，按用户此前要求后置。Mac只有登录、唤醒且Mail同步出新未读时才能巡检；60秒是本机检查间隔，不是从服务器收信起的送达承诺。

仅接入Mac Mail的邮件提醒，没有关闭Mail原生提醒，也没有接管其他应用通知。摘要截断、机器/群发规则、每日上限可能把重要邮件延后；当前不含重要性准确率提升或模型微调。未读超过每轮上限时只处理最新部分，每个邮箱未读超过1000封则明确报错；大量历史未读需先整理，不能承诺全量积压处理。

原生回读只能证明通知中心有记录。用户关闭通知、专注模式、清除通知或系统投递异常仍会影响实际可见性；历史HandedOff按原有保守去重规则不自动重发。
