# Mac电脑操控与国内出行接入

2026-10-17。用户已批准采用Cua Driver并在macOS开启其辅助功能和屏幕录制权限。

## 已接入的部分

Mac内置工具由48增加至52个：新增`computer_schema`、`computer_observe`、`computer_act`、`travel_prepare`。前三个入口支持35项已审核的Driver操作，涵盖应用和窗口、AX与截图、点击/双击/右击/拖动/滚动、键盘、菜单、剪贴板、窗口布局，以及隔离浏览器的页面、对话框、文件选择和下载操作。注册成功不代表35项在所有应用均经实测。

直接复用现有Rust工具循环和stdio MCP，无新增Rust依赖。独立CuaDriver.app固定0.36.0，安装包SHA256为`2a83cf9c3a2fa7ae27f3fe62e426aeca5acf76511bb14dd64d10ccb2de6aecae`；校验Apple开发者Cua AI, Inc.签名、公证及Bundle身份后安装。默认遥测已关闭。不安装大模型、虚拟机、录屏历史，也不重新构建“云熙本机助理”。

入口流程：先查看computer_schema，再观察精确窗口/标签，用本次observation_id申请一个动作，动作后重新观察。首次get_browser_state用pid/window_id绑定；后续用返回target_id和选定tab_id读取页面。不要把Edge首次运行的无标题弹窗当作about:blank主窗口。

界面动作逐次人工批准，CLI的--yes不能替代，私有审批仅在交互终端显示参数；全局云熙操作锁、共享版本、120秒期限及动作前消费阻止并发误用和旧观察重试。仍有用户及其他软件同时改变桌面的可能，进程内约束不等于OS沙箱。原图和私有参数/界面原文仅在本进程使用，台账与会话存脱敏定位和占位信息；恢复后重新观察。模型最终回复仍正常保存，因此不应在总结里复述凭证。

## 国内票务、酒店与日程

`travel_prepare`统一查询条件并提供正常网页链路：12306火车票、携程国内机票和酒店。准备工具本身不访问库存，也不把起价当作可订报价；需要继续用电脑操控读取页面。是否开售、席别/房型、数量、全税总价、行李/早餐与退改条件都须有本次页面证据。

选定后还需最终提交页复核与逐次批准。验证码、登录及支付交给用户；状态不明先查订单，不能再按一次提交。取消订单需先显示费用，取消成功不等于退款到账。独立供应商API尚未开通，RollingGo等渠道仍是调研候选。

真实订单回执产生后，复用已有mac_trip_plan/apply预排、revision审批与回读；联动受影响各日的固定安排、通勤、准备、到达后转场和入住退房。此轮没有创建真实订单或用户日程，不能声称端到端预订已通过。
