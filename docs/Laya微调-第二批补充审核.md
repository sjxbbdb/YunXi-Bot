# Laya 微调：第二批补充审核

**新增12个场景，全部待审核。原32条标签和留出分组不变。**

首轮全参数微调记住了训练样例，但原40题回归从36降到31。冻结编码器对照保持36/40，却没有明确提升。生产服务继续使用基础模型。

原16个训练场景中没有知识库/混合记忆、运行异常为真、邮件无需行动、稍后介入和无关邮件等标签。以下补充独立场景填补这些缺口，不移动已经看过的留出样例。

| 编号 | 情景 | 建议判断 | 理由 |
|---|---|---|---|
| N01 | 在导入的菜谱中找三人份番茄汤的用料，不需要参考我的口味。 | 知识库 | 查询公共资料内容，不翻私人偏好。 |
| N02 | 用已经导入的相机说明书查错误码E42的解释。 | 知识库 | 问的是设备文档。 |
| N03 | 结合我平常的口味和前天晚餐后不舒服的经历，帮我想想今晚吃什么。 | 混合记忆 | 长期偏好和具体经历都被明确提及。 |
| N04 | 参考我平时的出行习惯，以及上次旅途中临时改票的经历，整理这次出门的准备事项。 | 混合记忆 | 个人习惯与过去事件均相关。 |
| N05 | 磁盘已满，当前工作无法保存，新阻塞尚未告知。 | 现在回应；情绪支持：否；运行异常：是 | 有新的运行异常需要说明，不据此推断情绪支持需求。 |
| N06 | 磁盘空间充足，备份正常，无新事项。 | 保持安静；情绪支持：否；运行异常：否 | 正常运行与沉默均不构成主动打扰依据。 |
| N07 | 专注期间出现非紧急图片导出失败，用户要求结束后集中告知。 | 留待稍后；情绪支持：否；运行异常：是 | 保留需告知的异常，等约定时机再说。 |
| N08 | 导出全部成功，用户要求专注结束后再告知，目前尚未结束。 | 留待稍后；情绪支持：否；运行异常：否 | 有待告知结果但没有异常，遵守告知时机。 |
| N09 | 你购买的配件已送达：你的配件已在约定地点交付完成，仅供留存，无需签收、确认或回复。 | 稍后看；本人需行动：否 | 与本人有关的记录，可以稍后查看，无需本人操作。 |
| N10 | 误发的他人配送记录：上一封是其他收件人的包裹记录，与你无关，请忽略，不需要任何操作。 | 不主动提及；本人需行动：否 | 当前内容明确与使用者无关，无需提及或行动。 |
| N11 | 测试通知：这是一封自动连通性测试邮件，无业务内容，无需确认或回复。 | 不主动提及；本人需行动：否 | 无业务信息的测试噪音，无需行动。 |
| N12 | 你订阅的月度更新记录：这是你订阅的软件月度更新说明，仅供参考。本次没有紧急修复，不要求升级或回复。 | 稍后看；本人需行动：否 | 订阅信息有关联但不紧急，也没有本人待办。 |

可以回复“新增12条全部认可”，或按N编号修改。审核前不会把这些样例用于训练。

机器数据：[project-review-v3.json](../models/training/project-review-v3.json)。前32条仍为approved；N01–N12为pending。训练数据导出器会拒绝含待审核条目的版本。

即使补齐这12条，数据量仍很小。它们只是补覆盖的草案，不能代替足量独立场景。上游调研后，下一步优先扩大已审核数据，再比较多随机种子的 RLCD 与 soft-ce；具体见[首轮实测与上游调研](Laya项目微调-首轮实测与上游调研.md)。
