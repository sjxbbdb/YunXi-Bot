# 本地陪伴 T1：生命周期契约

状态：2026-10-24，已实现并验证。

## 决策

- **懒加载**：ChatService 启动 chat-server 时带 `--auto-local`，但 chat-server `ready` 时**不加载模型**；第一次 `chat` 输入才启动 `.venv-mlx` + 本机模型。
- **任务不唤醒**：`task` 输入直接走云端工作代理，不触发本机模型加载。
- **闲置卸载**：本机服务默认 **600 秒**无请求释放模型权重；Python 进程保留，下次请求自动重新加载。
  - `YUNXI_LOCAL_IDLE_UNLOAD` 可改秒数；`0` 关闭闲置卸载。
  - `启动本地模型.command` 同样默认 600 秒。
- **失败边界**：模型未安装/启动失败/超时，聊天明确报“本机模型未启动，这一轮没有上云”，绝不回落 DeepSeek。
- **进程归属**：自动拉起的子进程由 `LocalModelGuard` 持有；chat-server 正常退出时回收。异常 SIGTERM 可能残留，但空闲会释放显存。

## 验收证据

- App/chat-server `ready` 后 17872 端口未监听；发送第一条聊天后端口打开并出现 `route local=true`。
- 本机服务日志显示 `空闲 600 秒没有请求就释放显存`。
- 以 5 秒测试参数启动本机服务：`/health` 从 `ok` 变为 `idle`，日志确认“已释放显存（进程还在）”。
- 测试命令：`cargo test`、`cargo clippy -D warnings`、本机聊天端到端；结果记录在提交说明。
