# 本地陪伴：外部事实控制层

状态：2026-10-25。人格已还原原始版并冻结；本轮不改 persona。

## 原则

**模型只负责措辞，事实/身份/工具由 Rust 外层控制。**

- 人格：`data/persona.md`，38,249 字节，SHA-256 `7606512d...beccd`，只读
- 身份：显式“我叫 X / 以后叫我 X”解析进会话事实表，直接由外层应答
- 过去：没有长期记忆命中时，直接回答“这边没有记录”，不让模型编
- 实时：本地没有联网工具时，天气/新闻/价格/股价等直接回答无法核实
- 工具：Qwen9 的 `memory_search` / `knowledge_search` 真实调用，写台账
- thinking：能力已接入，但默认关闭；`YUNXI_LOCAL_THINKING=1` 显式开启

## 实测

| 用例 | 结果 |
|---|---|
| 无记忆问“还记得香菜吗” | **0.2s**，外层直答“没有记录” |
| 北京实时天气 | **0.1s**，外层直答“没有联网工具” |
| 说“我叫阿岚” | 外层直接返回“好，阿岚。记住了。” |
| 问“我叫什么” | **0.1s**，外层直答“你叫阿岚” |
| 显式 `memory_search` | 工具台账 `allow / ReadOnly / ok`，回复基于记录 |
| thinking 默认关闭 | 正常聊天可用 |
| thinking 开启 | Qwen9 + 完整人格下 4096 预算仍可能只思考不输出，超过 4 分钟；因此默认关闭 |

## thinking 结论

Qwen9 的 thinking 在这台 M2 Max 64GB 上、搭配完整 38KB 人格时不可作为默认：

- 2048 预算：只思考无正文
- 4096 预算：“你好”超过 4 分钟未完成
- 外部守卫可以保证事实，但不能降低模型 reasoning 的 token 成本

所以 thinking 做成显式开关，默认关闭；要真正日常使用，需要更小的思考预算/专门的推理引擎，不能靠简单加预算。

## 当前限制

- 旧训练知识中的**普通百科事实**仍无法逐条核验；本轮只硬性拦截用户过去和实时信息。
- 工具调用仍由模型选择；`memory_search` 已验证，但不是每条记忆问句都会显式调用（部分走自动召回）。
- 完整人格会放大占有/暴力式角色表达；人格不可改，这是已知取舍。
