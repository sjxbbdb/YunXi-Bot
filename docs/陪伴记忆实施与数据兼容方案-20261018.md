# 陪伴与记忆实施：数据兼容方案

承接《陪伴与记忆开源参考及重构建议-20261018.md》，用户已批准实施。人格、上下文、工具复用和通知修复直接进行；以下是持久化扩展的具体审阅范围。

## 数据扩展

- 新增对话观察事件，只保存用户原话中经过凭证过滤的有界文本、会话来源与时间；工具输出、网页、邮件和注入的记忆段不能冒充用户原话。
- 新增记忆提议及处置事件，包含逐字来源证据、候选类别、时间、替代哪条旧记忆；长期事实和偏好先待确认，接受后才成为正式记忆。明确纠正和忘记沿用人工操作入口。
- 待跟进事项也保留用户来源、有效时间和必要的工具定位；取消、延期、已经提醒分别有据可查。生成、投递、确认送达、回应分别记录；复用原通知回执，不把生成当送达。
- 扩展记忆的可选来源与有效期。旧记录缺字段时保留原语义；暂时状态不过期变成永久画像。正式画像仍通过原有确认流程。

## 升级与回退

沿用追加式 JSONL 台账，不改写旧事件、不删除历史，不添加数据库或运行时依赖。新版读取旧记录时使用明确默认值；新增事件及字段须有旧数据重建、重启、坏记录拒绝、有效期与忘记测试。

部署前备份台账、相关投影和当前可执行文件，记录哈希。先在副本与隔离数据目录验证，再启用新写入。旧版不能识别新事件，会拒绝读取；不得把新事件静默删掉来强行回退。需回退时停止后台、归档升级后的完整数据，恢复成套旧版本与升级前备份，并明确备份时间之后的数据仅保留在归档中，另行迁移，不能称为已无损降级。

本次不做审计历史的物理删除。忘记意味着停止召回、提炼复用和主动跟进；已有台账及历史会话仍属审计资料，不伪称彻底擦除。

## 实测后的职责调整（用户已批准）

真实 Laya 验收：用户明确要求面试后关心，约定时间已到、日历无改期、下午14点且3小时未打扰。模型返回 `Quiet`，未降级、未命中静默或间隔约束。这意味着单靠工程接通不能保证履行已经确认的跟进。

建议仅对新模块中**已逐次批准的跟进事项**调整：到期、未取消、未过期、来源有效、最新关联日历/待办未变化、静默与退避允许时，进入 DeepSeek 无工具表达；Laya 判断照常留作参考，不再撤销用户已批准的跟进。DeepSeek 仍可返回 `-` 表示没有值得说的内容。Laya 不可用也只记参考判断降级；生成、取材或投递失败仍不宣称送达。

不扩展为无依据主动打扰，不修改原有工具审批、邮件机制或模型微调。未获批准的记忆候选不会自动创建后台跟进。旧手动 `agent` 判断入口保留原模型门控；新后台明确区分“执行用户确认的跟进”与“模型自行决定开口”。

该调整在用户确认之前不切换生产后台。原始失败日志保留在本轮私有验收目录。

## 执行边界

后台只有经过代码限定的只读取材；写日历、改待办、发信及电脑操作仍走现有工具与审批。用户没有回应不代表读过或拒绝。模型异常、来源缺失、工具失败或过期信息均停止相应跟进并留明确降级记录。静默时段继续生效，陪伴与重要邮件的额度分开。

用户明确确认“已确认跟进按规则触发，Laya作参考”。原始Laya漏报样本保留，不作为已修复模型准确率的证据；不启动微调。
