# 图片传输与验收（2026-10-17）

当前在既有 DeepSeek 客户端与聊天工具循环中支持显式附图。模型仍为 `deepseek-flash`；图片采用 [DeepSeek 官方图像理解协议](https://api-docs.deepseek.com/zh-cn/guides/vision/) 的 `content` 数组，正文为 `text` 块，图片为 base64 data URL 的 `image_url` 块。纯文字仍发送字符串，不改变既有工具调用顺序。

## 使用

在项目目录执行：

```bash
cargo run -- think '说明这两张图的不同' --image '/完整路径/图一.png' --image '/完整路径/图二.jpg'
cargo run -- chat
```

进入聊天后输入：

```text
/image /完整路径/截图.png
请读出图片里的时间与地点。
右下角那一项呢？
```

`/image` 只将文件加入本轮队列，下一条普通输入才会连同图片发送给 DeepSeek；可多次附图。路径可含空格，也可整段使用单/双引号。`/image clear` 清空待发送队列，`/clear` 同时重置当前会话与待发送图片。分类或请求失败不把待发送队列冒称为已经成功处理；有效输入仍需通过原有 Laya 分类与审计。

单次入口不带提示词而只有 `--image` 时，默认请求描述图片。附图仅支持 DeepSeek，不自动启动本地生成模型。缺少参数、未知选项或不支持的提供方明确失败。

## 边界

- 按文件实际签名支持 PNG、JPEG、GIF、WebP，不信任扩展名；本机不实现完整解码器，完整解码由服务端校验。
- 单图最多 8 MiB，单次请求及会话持有的原图最多 8 张、合计 16 MiB。这是保守的本机传输限制，小于提供方最大额度。历史图片仍在上下文时会计入数量与大小；达到上限后减少本轮附图或新开会话。
- 只接受显式本机文件或开发接口 `ImageInput::from_bytes`；不自动抓取远端图片 URL，不读取邮件附件，不采集屏幕。图片只放在 `user` 消息中；system/assistant/tool 携图明确拒绝。
- 原图编码使用共享内存，在连续追问及工具往返中保留；上下文估算按每图最多 1024 token 保守计入，实际账单仍采用服务端 usage。
- 不把原图编码存到日志、费用台账或会话 JSON。原始文件留在用户原位置；模型写出的文字描述仍会保存在会话中。图片会发送给 DeepSeek，属于云端处理。
- 会话只存附图说明；跨进程恢复会提示重新附图。压缩只摘要文字，移出的原图不再可用，旧回答不能作为重新看过原图的证据。
- 图片不是工具授权。聊天继续走同一工具循环和审批；图片中的命令、二维码、网页提示不得替代用户指令或人工批准。
- 发送前的本机校验失败直接返回错误。图片请求的 HTTP 错误保留状态分类但不记录服务端正文；JSON/SSE 格式错误也不保留可能回显编码的解析诊断。已先用失败测试复现原始解析错误会回显响应内容，再修复。

## 工程验证

`cargo fmt --all -- --check`、`cargo build`、`cargo test`、`cargo clippy --all-targets -- -D warnings` 通过：CLI 92 项、core 1135 项，总计 1227 项通过，11 项既有真实环境测试保持 ignored。`cargo build --release` 通过；项目的 `启动.command` 已通过正式版本附图实测，无须重建原生 Mac 助理应用或重启邮件后台。

新增 13 项测试覆盖：Base64 标准向量及二进制补位；四种格式签名及 Debug 不含编码；空/未知/超大/非文件输入；数量、合计大小及角色限制；纯文字协议兼容、多图协议；真实本机 HTTP 收包（非流式/SSE、HTTP错误和畸形响应回显抑制）；工具往返、连续追问、待发送图与历史图的存档隔离；超限失败保留原会话；CLI 参数与含空格路径。原有聊天装配回归增加了附图且保留工具定义的分支。

## 真实 DeepSeek 验证

仅使用无隐私的两张合成 PNG，无真实截图、邮件或用户文件。使用本机既有凭证，临时数据目录与生产后台隔离，聊天测试采用 dry-run；未进行任何外部写操作。

| 场景 | 实际结果 |
| --- | --- |
| 单次非流式请求同时附两张图，提示词不包含答案 | 正确返回 `5729`、`8061`；API 请求约 1.24 秒，CLI 总耗时约 2.66 秒 |
| 流式聊天附图、下一轮不重复附图而追问颜色 | 先返回 `5729`，再返回 `红色`；两轮及本地分类总计约 2.94 秒 |
| 退出并恢复同一会话，要求核对原图 | CLI 明确提示原图未保存，模型回答“需要重新附图。”；该轮总计约 0.98 秒 |
| 检查隔离数据目录所有存档及台账 | 不含图片 data URL、原图 Base64 或凭证 |
| 正式版本经 `启动.command think --image` 发送单图 | 正确返回 `5729`，总耗时约 1.28 秒；正式版帮助列出新参数 |

原始合成图片、独立会话及机器可读报告位于本机忽略目录 `data/benchmarks/image-transport-20261017-191230/`，不提交到 GitHub。以上是当前网络下的小样本结果，不代表所有复杂截图、超大图片或持续视觉操作的识别准确率。
